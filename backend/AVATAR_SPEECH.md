# 小北面试官与曼波语音接入

## 已接入

- Pi Web 原生业务组件的 InterviewRoom 使用 CharacterView 中的透明 2D 小北头像，不再加载火箭 GLB。
- 静态角色资源在前端 public/avatar。包含已确认的软方脸造型、七种状态、动态特效、动作和音量嘴型。
- 视频/语音模式在提问阶段自动生成曼波 MP3；文字模式不自动播报。
- 前端通过 POST /api/interview/speech 获取 audio/mpeg 二进制，转成 Blob URL 交给头像播放。
- 暂停、结束、换题、开始输入、开启作答麦克风和关闭播报都会取消当前前端请求并停止旧音频。
- 重播问题按钮可以再次播报；接口失败不影响文字作答。
- 头像状态：待机 → 生成语音时思考 → 播放时说话 → 结束后倾听；反馈生成时思考，反馈展示时鼓励。

## 后端配置

后端进程环境变量：

- MAMBO_TTS_KEY：推荐显式设置，仅后端持有。
- MAMBO_TTS_API：可选，默认使用指定脚本的 mbAIscvip 接口。
- MAMBO_TTS_SOURCE：可选，未设置 KEY 时，从该 Python 文件静态读取 API、KEY 常量；默认是用户指定的本机 gen_tts_vip.py 路径。不会执行源脚本，不会触发原批量配音任务。

部署到其他电脑时应设置环境变量，不要依赖本机绝对路径，也不要把密钥写进前端。

## 启动

使用根目录启动脚本启动 FastAPI（默认 8000）和唯一前端 Pi Web（统一入口默认 5173）。无需独立头像演示服务或 Vite 前端。

前端入口： http://127.0.0.1:5173 （侧栏选择模拟面试）
后端健康检查： http://127.0.0.1:8000/health

头像静态资源仅维护在 [Pi Web public/avatar](<../pi-web/public/avatar>)；生产更新需要重建 Pi Web 并重启应用。

## 重要限制

- 当前供应商是先生成完整 MP3 再播放，不是真正流式 TTS。
- 停止按钮会取消前端等待和播放，但已经发送到供应商的合成不一定能取消。
- 微音量驱动嘴型不是精确音素同步；装饰声纹不表示录音。
- 摄像头仍走原来的授权流程；未擅自申请用户设备权限。麦克风识别仍是原项目未接入状态，不冒充已实现。
- 第三方收到的是播报题目文字，不发送摄像头画面或录音；准备页已给出提示。
- 路由沿用现有可游客访问的 FE 面试接口方式。上线前需为收费语音补充身份认证、额度、限速、并发队列及供应商使用条款检查。当前内存缓存最多 20 条，重启即清除。
- 全站 Brand/XiaominMark 未整体替换，本次只替换 AI 面试视频/语音房间中的旧火箭角色，避免影响其他品牌页面。
