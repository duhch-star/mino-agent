# Resume example previews

These PNGs are full first-page PDF renders. `classic` and `sidebar` are upstream author PDFs; the three additional previews are MINOS synthetic adapted examples with placeholder institutions and explicit instructions to supply real information. They are not personal resumes or claimed accomplishments.

See each original template directory's manifest and license for pinned upstream revisions and licensing. The original two PDFs are unchanged. New templates preserve upstream layout macros with free-font/XeTeX/Chinese compatibility adaptations; they do not claim pixel-identical upstream output. Rendered with pypdfium2 at scale 1.25. No browser PDF plugin is needed for these previews.

The UI explicitly labels author examples and does not save their contents into user resumes. Template-selection actions only populate a draft; the user must confirm and send it.
