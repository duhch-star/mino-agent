# Resume example previews

These PNGs are full first-page renders of the upstream author PDFs already distributed under `backend/app/resume_templates` in this repository. They are not user resumes or newly invented accomplishments.

| Image | Input PDF | Source |
| --- | --- | --- |
| classic.png | sb2nov/sourabh_bajaj_resume.pdf | https://github.com/sb2nov/resume |
| sidebar.png | deedy/deedy_resume-openfont.pdf | https://github.com/deedy/Deedy-Resume |

See each original template directory's manifest and license for pinned upstream revisions and licensing. No changes to original PDF layout, fonts, or author data were made. Rendered with pypdfium2 at scale 1.25 (765 × 990 pixels). No browser PDF plugin is needed for these previews.

The UI explicitly labels author examples and does not save their contents into user resumes. Template-selection actions only populate a draft; the user must confirm and send it.
