# 生成式 UI 与实时面试改造记录

## 参考项目（2026-10-26 查阅）

- assistant-ui（MIT）：https://github.com/assistant-ui/assistant-ui 。参考可组合消息/工具视图、流式状态、审批与后续建议，不替换现有 Pi SDK runtime。
- CopilotKit（MIT）：https://github.com/CopilotKit/CopilotKit 。参考声明式生成 UI、共享状态与人机确认；模型只能产生数据，不能注入 HTML、脚本或自动执行操作。
- LiveKit Agents：https://github.com/livekit/agents 。参考 STT/LLM/TTS 分层、轮次检测与打断模型。当前部署没有 WebRTC 服务，不将浏览器语音 + HTTP 音频伪称为全双工实时链路。

上述为设计与架构参考，未复制上游实现代码或引入其全部 SDK；现有 Pi runtime 保留。通用搜索工具本轮不可用，已直接获取三个官方仓库 README。

## 现有问题

1. 生成式协议仅有五种布局；需补充时间线、选择比较、技能矩阵等，并完善展开、复制、选择确认、键盘与移动端体验。
2. TTS 在全局锁内执行网络请求，使不同文本串行等待；供应商最长等待可达数分钟。
3. 缺失语音密钥会尝试读取硬编码外部脚本路径，不符合可移植部署。
4. 浏览器语音识别一次结束就提交，长回答容易被提前切断。
5. 无首响/生成/播放阶段测量，无法证明实时性。

## 第二轮已实现与证据

- 原生面试页不再让头像 iframe 播音，播放控制器统一持有 HTMLAudio / SpeechSynthesis，支持中止请求、停止播报、重播、语速与中文音色选择。
- 自动模式云端请求 6 秒内未就绪则尝试浏览器语音；实际 `playing` / `start` 事件才记首响。该值是浏览器事件估计，不是扬声器声学采样。
- 默认收音后先核对手动提交；可显式开启 1.8 秒完整结果稳定后的自动提交。中间转写不自动发送，停止/卸载撤销定时器。
- 卡片及语音 18 项单元测试、TypeScript 检查通过。生产构建并重启统一入口成功。
- Edge headless 在真实登录/真实面试会话上验证云端失败兜底、首响显示、停止/重播、草稿不自动发送，以及 390px 无横向溢出。音频与识别服务被确定性 mock：不能当作真实配音或云端延迟验证。
- 已生成桌面与手机截图供人工查看；当前模型无法读取图片，尚未声称完成视觉审查。

## 第三轮进展

- 网关不再序列化整段业务请求，只串行刷新凭据。新增测试证明慢语音未释放时两个业务请求仍完成、并发 401 只刷新一次。
- 卡片工具栏支持展开/折叠与显式复制；依据使用原生 details/summary；缺失依据有提示。首页添加成长路线、机会对比、能力盘点入口并修复重复 React key。
- 真实语音能力采样：云端未配置密钥，未发送供应商请求；Edge headless 检测到 3 个中文声音，Microsoft Huihui 本机声音完整播报结束，`start` 事件首响 257ms（单次采样、浏览器事件估计，不是扬声器环回测量，也不是全链路延迟）。
- 21 项卡片/语音/网关测试与 TypeScript 检查通过，生产构建成功。

## 第四轮进展与关键剩余问题

- 面试反馈加入 25 秒取消超时、请求长度限制、严格三维度/整数评分/有界文本校验及 Server-Timing。模型异常不返回伪造反馈。
- 等待中显示已耗秒数和慢响应提示，成功后分开显示模型往返与语音首响，避免混淆。
- 52 项后端测试通过，包含布尔/浮点/NaN 分数拒绝、异常数据拒绝、错误脱敏与真实端点计时头。生产已部署。
- 真实 LLM 单次测量：HTTP 200，往返 20722ms，其中服务端 20692ms；三维度评分、117 字口语反馈。未 mock。该数据证明全链路仍不满足低延迟目标，不能完成目标或把本地 257ms 当成完整面试延迟。
- 下一轮重点：流式反馈与口语短反馈/详细报告分阶段，降低首个有意义反馈等待；真实模型生成卡片验证；无云端配音凭据时保持本机可用，不擅取外部密钥。
- 浏览器声音自动选择已改为中文本机优先（该细小优化在本轮构建后修改，尚待下次构建部署）。

## 分期与验收

- 第一阶段：TTS 配置显式化、按文本去重、并发有界、超时有界、缓存及计时响应头；测试并发而不是只测成功响应。
- 第二阶段：丰富生成式卡片协议/布局，默认安全、明确本地状态与真实业务状态，配套组件及浏览器交互测试。
- 第三阶段：语音选项/状态面板、浏览器语音兜底、预加载和可中断播放、稳定轮次结束、真实延迟测量；网络服务失败不能阻止手动输入。
- 最终：生产构建、统一入口浏览器验收、桌面/移动端、无障碍与 reduced-motion 测试。供应商性能需真实采样，不承诺未经测量的毫秒延迟。
