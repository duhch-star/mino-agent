# 生成式 UI 与实时面试改造记录

## 参考项目（2026-10-26 查阅）

- assistant-ui（MIT）：https://github.com/assistant-ui/assistant-ui 。参考可组合消息/工具视图、流式状态、审批与后续建议，不替换现有 Pi SDK runtime。
- CopilotKit（MIT）：https://github.com/CopilotKit/CopilotKit 。参考声明式生成 UI、共享状态与人机确认；模型只能产生数据，不能注入 HTML、脚本或自动执行操作。
- LiveKit Agents：https://github.com/livekit/agents 。参考 STT/LLM/TTS 分层、轮次检测与打断模型。当前部署没有 WebRTC 服务，不将浏览器语音 + HTTP 音频伪称为全双工实时链路。

上述为设计与架构参考，未复制上游实现代码或引入其全部 SDK；现有 Pi runtime 保留。通用搜索工具本轮不可用，已直接获取三个官方仓库 README。

## 现有问题

1. 生成式协议仅有五种布局；需补充时间线、选择比较、技能矩阵等，并完善展开、复制、选择确认、键盘与移动端体验。
2. TTS 在全局锁内执行网络请求，使不同文本串行等待；供应商最长等待可达数分钟。
3. 缺失语音密钥会尝试读取硬编码外部脚本路径，不符合可移植部署。
4. 浏览器语音识别一次结束就提交，长回答容易被提前切断。
5. 无首响/生成/播放阶段测量，无法证明实时性。

## 第二轮已实现与证据

- 原生面试页不再让头像 iframe 播音，播放控制器统一持有 HTMLAudio / SpeechSynthesis，支持中止请求、停止播报、重播、语速与中文音色选择。
- 自动模式云端请求 6 秒内未就绪则尝试浏览器语音；实际 `playing` / `start` 事件才记首响。该值是浏览器事件估计，不是扬声器声学采样。
- 默认收音后先核对手动提交；可显式开启 1.8 秒完整结果稳定后的自动提交。中间转写不自动发送，停止/卸载撤销定时器。
- 卡片及语音 18 项单元测试、TypeScript 检查通过。生产构建并重启统一入口成功。
- Edge headless 在真实登录/真实面试会话上验证云端失败兜底、首响显示、停止/重播、草稿不自动发送，以及 390px 无横向溢出。音频与识别服务被确定性 mock：不能当作真实配音或云端延迟验证。
- 已生成桌面与手机截图供人工查看；当前模型无法读取图片，尚未声称完成视觉审查。

## 第三轮进展

- 网关不再序列化整段业务请求，只串行刷新凭据。新增测试证明慢语音未释放时两个业务请求仍完成、并发 401 只刷新一次。
- 卡片工具栏支持展开/折叠与显式复制；依据使用原生 details/summary；缺失依据有提示。首页添加成长路线、机会对比、能力盘点入口并修复重复 React key。
- 真实语音能力采样：云端未配置密钥，未发送供应商请求；Edge headless 检测到 3 个中文声音，Microsoft Huihui 本机声音完整播报结束，`start` 事件首响 257ms（单次采样、浏览器事件估计，不是扬声器环回测量，也不是全链路延迟）。
- 21 项卡片/语音/网关测试与 TypeScript 检查通过，生产构建成功。

## 第四轮进展与关键剩余问题

- 面试反馈加入 25 秒取消超时、请求长度限制、严格三维度/整数评分/有界文本校验及 Server-Timing。模型异常不返回伪造反馈。
- 等待中显示已耗秒数和慢响应提示，成功后分开显示模型往返与语音首响，避免混淆。
- 52 项后端测试通过，包含布尔/浮点/NaN 分数拒绝、异常数据拒绝、错误脱敏与真实端点计时头。生产已部署。
- 真实 LLM 单次测量：HTTP 200，往返 20722ms，其中服务端 20692ms；三维度评分、117 字口语反馈。未 mock。该数据证明全链路仍不满足低延迟目标，不能完成目标或把本地 257ms 当成完整面试延迟。
- 下一轮重点：流式反馈与口语短反馈/详细报告分阶段，降低首个有意义反馈等待；真实模型生成卡片验证；无云端配音凭据时保持本机可用，不擅取外部密钥。
- 浏览器声音自动选择已改为中文本机优先（该细小优化在本轮构建后修改，尚待下次构建部署）。

## 第五轮流式反馈

- 新增 `/api/interview/feedback/stream` NDJSON 流。要求模型先给完整 reply 字符串；只有完整解码后发布 preview，最终报告严格验证后才发布 complete；异常只发脱敏 error，不把 preview 当成功评分。
- 前端增量处理 UTF-8 分片，区分预览与最终报告，断流/取消/超时保留回答；页面离开撤销当前流，防止迟到结果污染新会话。
- 55 项后端测试通过；13 项流/语音/网关测试和 TypeScript 检查通过；生产构建部署成功。
- 真模型单次流采样：首段预览 12427ms（服务端12411ms），完整报告16629ms，三维度有效。相比上轮整包20722ms有改善，但不是受控同请求基准，更不能证明已满足实时性。
- 预览当前先展示，尚未并入提前播报队列。后续需要短口语优先、详细报告并行/延后及模型延迟策略；不要把“HTTP传输流式”说成模型首 token 很快。
- 构建后补了换题清理预览/计时的小改动，尚待下一次部署；不影响已测首段流传输。

## 第六轮短反馈与提前播报

- reply 提示收敛至25–45字、一到两句，只说一个具体优点和一个建议；报告维度仍保留。预览与完整报告共用稳定语音轮次，不在报告完成时重播；手动文字更正不会阻断已提交后的反馈播报。
- 真模型单次采样：首段7715ms（服务端7699ms），完整10345ms。明显优于上一条采样，但仍是不同网络时间单次观测，不能承诺7秒上限或声称实时目标完成。
- Edge实际页面、真实面试会话配合分阶段模拟流/媒体：确认报告未完成时已调用预览播报，报告完成后相同文本仅播放一次。55项后端测试通过，构建部署成功。
- 云端配音仍未配置。后续重点为首段延迟策略、真实模型生成卡片端到端、无障碍/主题与复盘体验；第5–6轮源码暂未再次推送GitHub，避免把未收尾流式改动混入之前已确认的提交。

## 第七轮续作

- 客户端报告校验与后端对齐：整数评分、三项有效维度、有界非空建议/优点/STAR文本、固定章节；拒绝重复预览、非法耗时，避免破损流进入页面。
- 真实供应商使用当前生成式提示词输出技能矩阵，通过严格协议解析并在 Edge 实际组件中渲染3项；八种布局展开/折叠/复制/依据/选择/390px与1100px回归通过。此为后端模型探针到实际组件，不等同于已验证Pi完整聊天链路。
- 修复暂停/重试收音覆盖现有草稿：新识别轮次以当前草稿为前缀，更新同一轮结果不重复拼接。24项卡片/流/语音测试与TypeScript检查通过。
- 剩余：Pi聊天端到端生成式验收、主题/无障碍进一步审查、真实语音识别环境测量和稳定低延迟；云端音色无密钥仍不可测，不擅自读取外部脚本凭据。

## 第八轮完整 Pi 聊天链路

- Edge 实际登录，通过 Pi 聊天输入验收场景，真实模型生成技能矩阵3项，点击后续操作只填入草稿，页面错误0。耗时26535ms包含完整卡片生成与操作，不属于面试延迟采样。未mock模型或Pi消息传输。
- 面试报告接入同一生成式 interview-feedback 组件：三维度进度条、回答依据展开、折叠与复制；新增完成题数/参考均分/来源概览，避免零次完成时误判为零分。
- 生产构建部署成功，沿用的动态导出依赖告警非阻断；真实语音识别及云端配音仍未完成环境验收，目标保持进行。

## 第九轮主题/键盘

- 三个新增布局使用 light-dark 分主题强调色；旧浏览器通过 @supports 保留主主题色，forced-colors 使用系统颜色与选中轮廓。
- Edge实际渲染检查六组（3布局×明暗）强调文字对比均>=4.5:1，键盘Enter可折叠/展开与查看依据。非全面WCAG审计，也未声称已人工看图验证。
- 面试准备页隐私说明同步新声音来源，明确在线声音、云端文字发送、浏览器语音识别的数据路径及默认先核对再提交，不再误称始终由曼波播报。
- 真实模型样本和八类布局交互回归继续通过。

## 第十轮配置感知配音

- 自动模式读取有界3秒的speech/config；未配置或未知时直接使用浏览器声音，不再每轮等待必然失败的云端请求。读取结果只影响后续轮次，不在播报中途触发自动重播；显式曼波选择仍保留，可清楚展示失败并手动切换。
- 页面显示自动模式实际可用性，未配置云端时也可选中文浏览器音色；13项语音/流测试和TypeScript检查通过，生产构建部署通过。
- 此优化消除无效云端调用，不代表模型响应时间或真实声学延迟下降到目标值；仍需多样本端到端延迟采样及真实设备验收。

## 第十一轮多场景真实链路测量

- 新增三场景浏览器探针，真实模型+本机慧慧声音，无媒体mock；计时为语音start事件而非声学测量。初测3次仅1次成功，复测3次2次成功，不隐藏失败样本。
- 复测成功样本：首段3796/5151ms，语音启动4220/5179ms，语音本身启动423/28ms，完整报告6142/8652ms；数据分析样本14140ms后格式无效。主要风险为模型结构化输出稳定性，尚不能宣称实时目标完成。
- 后端增加脱敏timeout/invalid/upstream分类；错误仍保留回答，不造评分。55项后端回归与生产构建通过，新增分类测试后面试专项10项通过。
- 页面首段计时改为提交开始至预览抵达，包含答案保存与网络，不再直接当作服务端耗时展示。真实会话配合模拟流的提前播报/复盘/手机验收通过。
- 下一步优先收敛模型输出协议稳定性，再作更多样本；不应以自动重试掩盖错误或轻率放宽评分校验。

## 第十二轮类型约束与失败定位

- 独立数据分析探针3次均合法，不能复现上一轮错误，因此不声称已找到唯一根因。仅记录字段类型和长度，不保存模型原文或凭据。
- 提示补充精简的字段/类型示例和长度建议，强调示例分数不是默认分、不得复制占位文字；流生成温度0.2，评分校验完全不放宽。错误增加固定json/schema分类，方便后续区分截断和结构错误。
- 56项后端测试通过，服务重启部署。真实三场景复测3/3完成；首段5886/7914/9894ms，声音start5915/8778/9927ms，报告9683/11793/14572ms（此处按升序列出，非同一场景行）。仅小样本，成功率改善不构成稳定性保证，首响仍不满足低延迟期望。
- 下一步应评估独立短口语通路与详细报告解耦或可配置低延迟模型，而不是继续用装饰动画掩盖等待；不得擅自改变私有模型密钥/供应商。

## 第十三轮短口语方案否决与截断处理

- 独立短口语、120token、相同供应商3次探针：两次0正文（5757/6001ms），一次40字（首token3810ms/完成4347ms）。因可靠性不足，不将双请求方案接入生产，不增加用户请求开销。探针原先在截断检测上线前执行，不能断言0正文原因就是长度耗尽。
- LLM SSE适配器现在识别finish_reason=length，抛出固定类型异常；面试流返回feedback_truncated，保留回答与预览，不进入成功评分。其他正常流行为不变，新增模拟SSE正常/截断测试。
- 下一步需评估可选、显式配置的低延迟面试模型和生成预算，而非使用空洞确认音伪装有效反馈。

## 第十四轮独立模型/预算入口

- 新增服务端INTERVIEW_LLM_MODEL（空值继承LLM_MODEL）、INTERVIEW_MAX_TOKENS（512..2400，默认1000）、INTERVIEW_TEMPERATURE（0..1，默认0.2）。流式及普通反馈均使用；同供应商/key，不增加凭据或更改私有.env。
- 模型选择作为请求局部参数传入，不临时改写全局settings，避免并发污染其他AI功能；浏览器不接触这些配置值或密钥。
- 61项后端回归通过，包括参数越界/NaN和局部覆盖隔离测试。环境模板列出操作说明，变更后重启后端；需要管理员先自行确认候选模型供应商支持与价格，再测试，配置入口本身不证明速度改善。

## 第十五轮能力矩阵筛选

- 能力矩阵新增全部/优势/待提升/待确认筛选，显示每类计数与当前结果数；筛选完全本地，不重写证据或评分。未提供/不适用状态归待确认，不把未知当作零分。
- 过滤后没有项目显示可恢复的空结果提示；44px按钮、aria-pressed、状态播报与键盘Enter切换。
- 12项卡片协议/SSR测试通过；Edge实际组件验证空结果/恢复全部/待确认数量、明暗对比、八布局交互及390px布局通过，真实供应商样本卡片渲染仍通过。

## 第十六轮主动取消等待

- 分析反馈中新增取消按钮，先使当前请求身份失效再abort；保留草稿、pendingAnswer和已有预览，但不加入评分。随后可重试或结束，不必等待25秒模型截止。
- 取消会停止预览播放并阻止自动收音（answerError门控），预览继续明确标记尚无完整报告。客户端取消不能保证供应商已停止计费。
- 浏览器验收新增取消分支：真实会话配合可取消模拟流，验证读取器取消、等待后无迟到评分、草稿保留且可结束；正常分支继续检查提前播报/不重播/复盘手机布局。

## 第十七轮上游结束判定

- SSE适配器要求正常finish_reason或[DONE]标志；无标志EOF视为断流，不会因为局部字符串恰好能解析而认定成功。兼容只发[DONE]和只发stop的供应商；length、content_filter、未知失败结束不成功。
- 新增断流/内容过滤/仅stop/仅DONE测试，继续保留原length回归；不改变实际供应商/模型配置。

## 第十八轮复盘导出

- 手动导出本地Markdown，包含原始问答、已完成参考评分/依据/建议/STAR示例与对话；明确非招聘判断，取消/失败回答只可在对话出现，不进入评分。
- 内容转义Markdown/HTML标记，避免模型或用户文字在后续阅读器成为活动链接/嵌入HTML。固定文件名，不把岗位文字当下载路径；临时ObjectURL回收。
- 页面提醒导出含个人经历，点击才生成，不自动下载/上传。3项内容/未完成隔离/转义测试与TypeScript检查通过。

## 第十九轮浏览器语音失败恢复

- getVoices同步失败不阻止默认中文播报；speak同步异常清理看门狗并回到idle，提供重播/文字提示；停止后缓存的迟到onstart不再启动计时器或改变状态。
- 新增同步异常与迟到回调测试，18项语音/流/导出回归及TypeScript通过。本轮不属于真实设备识别或延迟达标证据。

## 第二十轮取消后重试验收

- 增加真实会话+模拟流的取消后重试模式，监测answers网络请求：同一回答重试只保存1次；两个尝试各预览播放1次，最终只有1条完成反馈卡片并可导出参考分。
- 回答输入增加明确可访问名称、字数提示及4000字输入上限（服务端校验继续保留）；语音转写仍受提交前校验，不静默截断语音文本。
- 此为链路回归，不是新模型延迟或真实麦克风可用性证据。

## 第二十一轮识别实例隔离

- 每个浏览器识别实例增加身份和失败状态门控，onend后立即失效；旧实例迟到result/start/error不覆盖新轮次，识别报错后的结果也不会重新触发自动提交。
- 构造识别器异常转换为可恢复错误，start异常明确停止收音状态；始终保留文字输入。新增三个异常/重启测试，13项语音测试与TypeScript检查通过。

## 第二十二轮复制快照

- 统一plain-text格式化，复制保留状态、依据和有据参考分；无依据分数不复制，缺失状态标为待确认。附本地勾选/选择不代表执行、投递或业务写入的说明，不把组件本地状态冒充平台记录。
- 13项卡片协议/SSR/复制测试通过；Edge验证剪贴板拒绝显示失败提示，八布局、键盘、明暗对比及移动布局回归通过。
